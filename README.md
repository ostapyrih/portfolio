# ostapyrih.com

Personal portfolio of Ostap Pyrih - built with React, Vite, Tailwind CSS and Motion.

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

The static site is generated in `dist/`.

## Edit content

All personal content (bio, experience, education, skills, projects, contacts) lives in `src/data/resume.ts`.
